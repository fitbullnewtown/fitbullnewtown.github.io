## Upload / update

1. Download and extract `fitbull-premium-website.zip`.
2. Open the `fitbullnewtown.github.io` GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload all items inside the extracted `fitbull-premium` folder — including the `assets` folder. Do not upload the outer folder itself.
5. Commit the changes to `main`.
6. In **Settings → Pages**, keep **Deploy from a branch**, select `main` and `/(root)`.
7. Wait for the GitHub Pages deployment to finish, then open `https://fitbullnewtown.github.io/`.
